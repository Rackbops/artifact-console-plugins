# @rackbops/ac-plugin-hello-remote

The reference plugin for [artifact-console-plugins](../../README.md): one panel, one card, and a
`GET /ping` route, installable from this repo's index into any `artifact-console` host.

It contributes nothing beyond proving the third-party install path works end to end — see
`@rackbops/ac-plugin-contract`'s own `AUTHORING.md` for how to build a real plugin against the
same ABI this one uses.
